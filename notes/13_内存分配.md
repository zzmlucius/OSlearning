物理页结构 struct run *run内嵌在物理页前八个字节



/kernel/kalloc.c

**链表实现O(1)的分配和释放**

- 数据结构: 
```c
struct run {
  struct run *next;
};

struct {
  struct spinlock lock;
  struct run *freelist; // 空闲链表表头
} kmem;
```

- 方法:(outline)
```c
void *kalloc() {
    struct run *r;
    r = freelist;
    freelist -> next = r; // 去头
    return r;
}



void kfree(void*) {
    struct run *p;
    memset(p, 1, PGSIZE);
    p -> next = freelist;
    freelist = p;         // 头插法
}
```
